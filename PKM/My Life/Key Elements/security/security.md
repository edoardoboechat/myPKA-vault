# Security

## What this covers

Android application security analysis, vulnerability assessment, APK inspection, malware detection, OWASP compliance, and secure development practices.

## What good looks like

- Comprehensive APK vulnerability scans with actionable findings
- Automated security checks integrated into development pipelines
- Clear remediation guidance for identified issues
- OWASP MSTG compliance verification

## What I am ignoring

- Network penetration testing (separate domain)
- iOS security (different platform, different tools)
- Desktop application security (mobile focus only)
